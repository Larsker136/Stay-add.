1.1Data representation

Counting with only two digits

A computer is built from billions of tiny switches that are either on or off. So it stores every number, letter and instruction in binary — base 2 — and programmers often write those long binary strings in hexadecimal to keep them short.

1

Understand

Seven sections and a checklist

1.1.1

What is binary?

  • computers are made of logic gates and switches that have only two states: on and off — written as 1 and 0
  • so all data and instructions must be converted to binary (base 2) before a computer can process them
  • one binary digit is a bit; 4 bits make a nibble; 8 bits make a byte
  • humans normally count in denary (base 10), using the digits 0–9
Number systemBaseDigits usedPlace values (right to left)
Denary100–91, 10, 100, 1000 …
Binary20, 11, 2, 4, 8, 16, 32, 64, 128 …
Hexadecimal160–9, A–F1, 16, 256, 4096 …
1.1.2

Converting between binary and denary

Binary → denary: write the place values above the bits, then add up the place values where there is a 1.

1286432168421
0100110164 + 8 + 4 + 1 = 77

Denary → binary: work from the largest place value down. If it fits, write 1 and subtract; if not, write 0.

150: 128 fits → 1, left 22 · 64 → 0 · 32 → 0 · 16 fits → 1, left 6 · 8 → 0 · 4 fits → 1, left 2 · 2 fits → 1, left 0 · 1 → 0 = 1001 0110

With 8 bits the smallest value is 0 and the largest is 255 (all 1s). In general n bits store 2ⁿ different values.

1.1.3

What is hexadecimal?

  • hexadecimal (hex) is base 16: it uses 0–9 then A=10, B=11, C=12, D=13, E=14, F=15
  • one hex digit stands for exactly 4 bits (a nibble), so a byte is always two hex digits
  • it is used because it is shorter and easier for humans to read than binary and fewer mistakes are made copying it — but the computer still stores binary
Where hex is usedExample

1.1.4

Converting hexadecimal

Hex ↔ binary: convert each hex digit to 4 bits, or split the binary into groups of 4 from the right.

B7 → B = 1011, 7 = 0111 → 1011 0111 · 0011 1100 → 3, C → 3C

Hex → denary: multiply the left digit by 16 and add the right digit.

B7 = 11 × 16 + 7 = 183 · 3C = 3 × 16 + 12 = 60

Denary → hex: divide by 16; the whole-number answer is the first digit, the remainder is the second. 200 ÷ 16 = 12 remainder 8 → C8.

1.1.5

Adding binary numbers

Add column by column from the right, carrying into the next column, just like denary addition.

Column adds up toWriteCarry
0 + 000
0 + 1 or 1 + 010
1 + 1 (= 2)01
1 + 1 + 1 (= 3)11

Overflow If the answer needs more bits than are available — a carry out of the leftmost bit of a byte — an overflow error happens. The 9th bit is lost and the stored result is wrong. An 8-bit register can only hold 0–255.

1.1.6

Logical binary shifts

  • a logical shift moves every bit left or right by a number of places; the empty places are filled with 0s
  • each shift left multiplies by 2; each shift right divides by 2
  • bits shifted off the end are lost — so a left shift can cause overflow, and a right shift loses precision (the answer is rounded down)

0001 0110 (22) ← 2 places = 0101 1000 (88) = 22 × 4

1.1.7

Positive and negative binary integers: two’s complement

  • in two’s complement the leftmost bit (the most significant bit) has a negative place value: −128 in a byte
  • if the MSB is 0 the number is positive; if it is 1 the number is negative
  • an 8-bit two’s complement number holds −128 to +127
−1286432168421
11101100−128 + 64 + 32 + 8 + 4 = −20

To write a negative number: write the positive version in binary, invert every bit (0↔1), then add 1.

−20: 20 = 0001 0100 → invert 1110 1011 → add 1 → 1110 1100

1.2Data representation

Letters, sounds and pictures as numbers

A character set gives every letter a number. A sound is measured thousands of times a second. A picture is cut into a grid of coloured dots. In every case the more bits you use, the better the copy — and the bigger the file.

1

Understand

Three sections and a checklist

1.2.1

Character sets

  • a character set is a list of characters a computer can use, each with a unique binary code
  • when you press a key, the computer stores the code for that character
  • codes are in order: in ASCII ‘A’ = 65, ‘B’ = 66 … and ‘a’ = 97, so sorting text can compare codes
ASCIIUnicode
Bits per character7 bits (extended ASCII: 8)up to 32 bits (commonly 16)
Characters128 (256 extended)over a million possible
CoversEnglish letters, digits, punctuation, control codesalmost every written language, symbols and emoji
Trade-offless storage per charactermore characters, but uses more storage
1.2.2

Representing sound

  • sound is an analogue wave; to store it, the wave’s amplitude (height) is measured at regular intervals — sampling — and each measurement stored in binary
  • sample rate: the number of samples taken per second (hertz, e.g. 44 100 Hz)
  • sample resolution: the number of bits used to store each sample (e.g. 16 bits)
  • a higher sample rate and higher resolution give a more accurate recording that sounds closer to the original, but a larger file
1.2.3

Representing images

  • a bitmap image is a grid of pixels (picture elements); each pixel’s colour is stored as a binary number
  • resolution: the number of pixels in the image — width × height (e.g. 1920 × 1080)
  • colour depth: the number of bits used for each pixel; n bits give 2ⁿ colours (1 bit = 2 colours, 8 bits = 256, 24 bits ≈ 16.7 million)
  • increasing the resolution or the colour depth improves the quality of the image but increases the file size

1.3Data representation

How big is the file, and how much smaller can it get?

Every file’s size can be worked out from how it is stored. Compression then shrinks it — either by throwing detail away, or by spotting patterns and writing them more briefly.

1

Understand

Four sections and a checklist

1.3.1

Units of data storage

UnitSize
bita single 0 or 1
nibble4 bits
byte8 bits
kibibyte (KiB)1024 bytes
mebibyte (MiB)1024 KiB
gibibyte (GiB)1024 MiB
tebibyte (TiB)1024 GiB
pebibyte (PiB) · exbibyte (EiB)1024 TiB · 1024 PiB

Why 1024? Memory is built in powers of 2, and 2¹⁰ = 1024. Cambridge uses the binary prefixes KiB, MiB, GiB.

1.3.2

File size calculation

image file size (bits) = width × height × colour depth

sound file size (bits) = sample rate × sample resolution × length in seconds

  1. image 800 × 600, 8-bit colour: 800 × 600 × 8 = 3 840 000 bits
  2. ÷ 8 = 480 000 bytes; ÷ 1024 = 468.75 KiB

For stereo sound, multiply by 2 (two channels).

1.3.3

Introduction to compression

Compression reduces the size of a file. This means it:

  • uses less storage space on a device
  • is faster to transmit over a network and uses less bandwidth
  • takes less time to upload and download, and streams more smoothly
1.3.4
