5.1The internet & its uses

The internet is the roads; the web is one kind of traffic

The internet is the worldwide network of connected computers. The World Wide Web is the collection of web pages carried over it — found by URL, translated by DNS, delivered by HTTP.

5.1.1

The internet and the World Wide Web

InternetWorld Wide Web (WWW)
a global network of interconnected networks — the infrastructure (cables, routers, servers)a collection of websites and web pages, accessed using the internet
carries email, file transfer, video calls, online games … and the webpages are written in HTML and linked by hyperlinks
5.1.2

Uniform resource locators (URLs)

A URL is a text-based address for a web page. It has three main parts:

https:// · www.example.com · /learn/binary.html

  • protocol — http or https
  • domain name — the name of the web server
  • web page / file name — the path to the resource on that server
5.1.3

HTTP and HTTPS

  • HTTP (hypertext transfer protocol) is the set of rules for transferring web pages between a web server and a browser
  • HTTPS is the secure version: data is encrypted using SSL/TLS, so it is meaningless if intercepted — shown by a padlock in the browser
5.1.4

Web browsers

A web browser is software that requests, receives and renders HTML into a viewable web page. Other functions:

  • storing bookmarks and favourites; recording user history
  • allowing multiple tabs; navigation with forward and back buttons
  • storing cookies; providing an address bar
  • running active scripts such as JavaScript
5.1.5

Retrieving a web page

  1. the user types a URL into the browser (or clicks a link)
  2. the browser sends the domain name to a DNS (domain name server)
  3. the DNS looks up the matching IP address; if it doesn’t have it, it asks another DNS server
  4. the IP address is returned to the browser
  5. the browser sends an HTTP(S) request to the web server at that IP address
  6. the web server sends back the web page as HTML
  7. the browser renders the HTML and displays the page
5.1.6

Cookies

  • a cookie is a small text file stored by the browser on the user’s device, created by a website
  • session cookies are temporary — deleted when the browser closes (e.g. items in a shopping basket while you browse)
  • persistent cookies stay until they expire or are deleted
  • uses: saving login details, remembering preferences and language, keeping items in a shopping basket, tracking browsing to show targeted adverts

5.2The internet & its uses

Money that exists only as data

Digital currency is never printed. Many digital currencies keep their records on a blockchain: a shared, chained list of transactions that is very hard to change once written.

1

Understand

Two sections and a checklist

5.2.1

Digital currency

  • a digital currency exists only electronically — there are no physical coins or notes
  • it is used to pay for goods and services online, transferred between digital wallets
  • some (cryptocurrencies) are decentralised: not controlled by a bank or government
5.2.2

Blockchain

  • a blockchain is a digital ledger: a time-stamped series of records of transactions that cannot be altered
  • each block holds transaction data, a timestamp, its own hash and the hash of the previous block, linking the blocks into a chain
  • copies of the blockchain are held on many computers in the network, so a change on one copy is noticed and rejected
  • changing a block would change its hash and break every later link — this makes tampering very difficult

5.3The internet & its uses

Threats online, and how to defend against them

Some attacks guess passwords, some flood a server, some trick a person into handing over details. Each one has defences — some technical, some just careful habits.

1

Understand

Two sections and a checklist

5.3.1

Cyber security threats

ThreatWhat it is · aim
Brute-force attacktrying every possible password combination until one works · to gain access
Data interceptionstealing data while it is being transmitted, e.g. with a packet sniffer or on unsecured wi-fi
Distributed denial of service (DDoS)many computers (often a botnet of infected machines) flood a server with requests so it cannot respond to genuine users
Hackinggaining unauthorised access to a computer system, to steal, change or delete data
Malwaremalicious software: virus (attaches to files, replicates when run), worm (replicates by itself across networks), Trojan horse (disguised as useful software), spyware (records activity, e.g. keystrokes), adware (unwanted adverts), ransomware (encrypts files and demands payment)
Phishingfake emails or messages that look genuine, persuading the user to click a link and enter personal details
Pharmingmalicious code redirects the user from a genuine website to a fake one, even if the correct URL was typed
Social engineeringmanipulating people into giving away information or access, e.g. pretending to be IT support on the phone
5.3.2

Keeping data safe

DefenceHow it helps
Access levelsusers can only see and change the data they need
Anti-malware (anti-virus, anti-spyware)scans files for known malware and quarantines or deletes it
Authenticationpasswords (long, mixed characters), biometrics (fingerprint, face), two-step verification (a code sent to a phone as well as the password)
Automatic software updatespatch security weaknesses quickly
Checking emails and URLslook for spelling mistakes, odd tone and suspicious links before clicking
Firewallmonitors traffic in and out of a network and blocks traffic that doesn’t meet set rules
Privacy settingscontrol who can see personal information on social media and websites
Proxy serversits between users and the internet: hides the user’s IP address, filters traffic and can absorb DDoS attacks
Secure socket layer (SSL)encrypts data between browser and server (HTTPS) using digital certificates
