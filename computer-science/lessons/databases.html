9.1Databases

Records in rows, fields in columns

A database stores data in tables so it can be searched, sorted and updated quickly. Every record needs one field that is never repeated — the primary key.

1

Understand

Three sections and a checklist

9.1.1

What is a database?

  • a database is a structured, persistent collection of data
  • it lets users search, sort, add, edit and delete data quickly and accurately
  • at IGCSE you work with single-table databases
9.1.2

Tables, records and fields

TermMeaning
Tablea collection of related records, e.g. Students
Recordall the data about one item — one row
Fieldone piece of data about each item — one column, e.g. Surname

Validation (range, presence, format, length, type checks) can be set on fields so that only sensible data is stored.

9.1.3

Data types and primary keys

Data typeUse for
text / alphanumericnames, IDs, phone numbers (not used for calculations)
charactera single character, e.g. a grade
Booleanyes/no, true/false
integerwhole numbers
realnumbers with decimals, e.g. price
date / timedates and times

A primary key is a field that uniquely identifies each record. Telephone numbers are stored as text because they may start with 0 and are never used in calculations.

9.2Databases

Ask the database a question

Structured Query Language (SQL) asks a database for exactly the records and fields you want, in the order you want them.

1

Understand

Three sections and a checklist

9.2.1

SELECT, FROM, WHERE

SELECT FirstName, Score
FROM Students
WHERE Form = '10A';
  • SELECT: the fields to show (* means all fields)
  • FROM: the table
  • WHERE: the condition records must meet; text in single quotes, numbers without
9.2.2

ORDER BY, AND, OR

SELECT FirstName, Surname
FROM Students
WHERE Age = 15 AND Score > 80
ORDER BY Surname ASC;

AND: both conditions true · OR: at least one true · ORDER BY … ASC (A→Z, smallest first) or DESC.

9.2.3

SUM and COUNT

SELECT COUNT(*) FROM Students WHERE Library = TRUE;
SELECT SUM(Score) FROM Students WHERE Form = '10B';

COUNT gives the number of matching records; SUM adds up a numeric field over the matching records.
