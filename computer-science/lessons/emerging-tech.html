6.1Automated & emerging technologies

Systems that run themselves

An automated system measures, decides and acts with no human in the loop: sensors feed a microprocessor, which compares readings with stored values and drives actuators — round and round.

1

Understand

Two sections and a checklist

6.1.1

What is an automated system?

An automated system is a combination of software and hardware designed to carry out a task without human intervention. It is made of:

  • sensors — measure physical conditions (temperature, light …) and send data
  • a microprocessor — receives the data (converted to digital by an ADC), compares it with stored preset values and decides what to do
  • actuators — motors, valves, pumps, heaters: carry out the action

The process repeats continuously, so the system keeps correcting itself — a feedback loop.

6.2Automated & emerging technologies

Robots: built, wired and programmed

A robot is a machine with a body, sensors, a processor and motors — and a program that tells it what to do. It can repeat a task perfectly, but it only does what it was programmed to do.

1

Understand

Three sections and a checklist

6.2.1

What is robotics?

Robotics is the branch of computer science that combines the design, construction and operation of robots. Robots are used in factories, homes, hospitals, farms, space and more.

6.2.2

Characteristics of a robot

  • a mechanical structure or framework — a body, arms, wheels or legs
  • electrical components — sensors to detect the environment, a microprocessor to process the data, and actuators (motors) to move
  • programmable — it follows a program; some can be re-programmed for a new task

Not a robot A device with no program controlling its movement — a remote-controlled toy driven only by a human — is not a robot.

6.3Automated & emerging technologies

Machines that reason and learn

Artificial intelligence imitates human thinking. An expert system reasons with rules written by experts; machine learning finds its own patterns in data and gets better with more of it.

1

Understand

Three sections and a checklist

6.3.1

What is artificial intelligence?

Artificial intelligence (AI) is a branch of computer science dealing with the simulation of intelligent behaviour by computers. Characteristics of AI:

  • the collection of data and the rules for using that data
  • the ability to reason — to draw conclusions from the data
  • it can include the ability to learn and adapt (machine learning)

Examples: voice assistants, chatbots, face recognition, recommendation systems, self-driving cars.

6.3.2

Expert systems

PartRole
Knowledge basea database of facts about the subject, collected from human experts
Rule basea set of rules (IF … THEN …) for using the facts
Inference engineapplies the rules to the facts to reach conclusions; decides which questions to ask
Interfacelets the user enter answers and see the results, often with an explanation of how the conclusion was reached

Used for medical diagnosis, fault finding in cars or machines, mineral prospecting, financial planning, chess.

6.3.3

Machine learning

  • in machine learning a program is not given explicit rules: it is trained on large amounts of data, finds patterns, and uses them to make predictions or decisions
  • it can change its own rules and improve its performance as it is given more data — it learns from experience
  • examples: spam filters that learn which emails are junk, product recommendations, image and speech recognition
