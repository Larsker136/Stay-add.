3.1Hardware

The CPU: fetch, decode, execute

The central processing unit runs every program the same way: fetch the next instruction from memory, work out what it means, do it — billions of times a second.

1

Understand

Six sections and a checklist

3.1.1

The CPU

  • the central processing unit (CPU) processes instructions and data that are input into the computer so that the result can be output
  • a microprocessor is a type of integrated circuit on a single chip that contains a CPU
3.1.2

Von Neumann architecture

In the von Neumann (stored-program) model, instructions and data are both stored in the same memory, and the CPU fetches them one at a time.

ComponentRole
Arithmetic logic unit (ALU)carries out calculations and logical operations (comparisons)
Control unit (CU)decodes instructions and sends control signals to manage the flow of data through the CPU
Program counter (PC)holds the address of the next instruction to be fetched
Memory address register (MAR)holds the address of the memory location being read from or written to
Memory data register (MDR)holds the data or instruction fetched from, or to be written to, memory
Current instruction register (CIR)holds the instruction being decoded and executed
Accumulator (ACC)holds the result of calculations done by the ALU
Address buscarries addresses from the CPU to memory — one direction
Data buscarries data and instructions between the CPU and memory — both directions
Control buscarries control signals (e.g. read, write, clock) — both directions
3.1.3

The fetch–decode–execute cycle

  1. Fetch: the address in the PC is copied to the MAR; it is sent along the address bus to memory; the instruction at that address is sent along the data bus to the MDR; it is copied to the CIR; the PC is incremented
  2. Decode: the control unit decodes the instruction in the CIR
  3. Execute: the instruction is carried out — for example the ALU does a calculation and the result goes in the accumulator
3.1.4

CPU performance

FactorEffect
Clock speed (GHz)the number of cycles per second; higher → more instructions fetched and executed per second
Number of coreseach core can process instructions independently; more cores → more instructions at once (if the software can split the work)
Cache sizecache is very fast memory inside the CPU storing frequently used instructions and data; larger cache → fewer slow trips to RAM

Not always faster Doubling the cores doesn’t double the speed: some tasks can’t be split, and the cores must communicate with each other.

3.1.5

Instruction sets

An instruction set is the list of all the commands (machine code operations) a particular CPU can process — for example ADD, LOAD, STORE, JUMP. Programs must be translated into this set before the CPU can run them.

3.1.6

Embedded systems

  • an embedded system is a computer system with a dedicated function inside a larger device
  • examples: washing machines, microwave ovens, central heating, security systems, traffic lights, vending machines, car engine management
  • usually small, low-power and cheap to mass-produce; often controlled by firmware stored in ROM
  • a general-purpose computer (a laptop) can do many tasks; an embedded system does one

3.2Hardware

Getting data in, getting results out

Input devices turn the world — a keypress, a photo, a temperature — into binary. Output devices turn binary back into light, sound, movement or print.

1

Understand

Three sections and a checklist

3.2.1

Input devices

DeviceHow it works / use
Barcode scannera laser or light shines on the black and white bars; the reflected light is read by sensors and converted to a number (e.g. shop checkouts)
QR code scannera camera captures the 2D pattern of squares, which can store much more data (e.g. a web address)
Digital cameralight passes through a lens onto a sensor made of millions of light-sensitive elements; each becomes a pixel value
Keyboardeach key press completes a circuit; the character code is sent to the computer
Microphonesound vibrates a diaphragm, creating an electrical signal that is sampled and converted to binary
Optical mousean LED lights the surface; a small camera takes many images per second and compares them to work out the movement
2D and 3D scannerslight scans a document (2D) or lasers measure the shape of an object from many angles (3D)
Touch screensresistive: two layers pressed together complete a circuit (cheap, works with gloves); capacitive: a finger changes the electric field at that point (multi-touch, clearer); infrared: a grid of infrared beams is broken by the touch
3.2.2

Output devices

DeviceHow it works / use
Actuatora motor, valve, pump or switch that produces movement from a signal (e.g. opening a window)
DLP projectormillions of tiny mirrors tilt to reflect light towards or away from the lens
LCD projectorlight passes through liquid crystal panels that let through red, green and blue
Inkjet printertiny droplets of ink are squirted onto the paper from a moving print head (thermal bubble or piezoelectric)
Laser printera laser draws the page as static charge on a drum; toner sticks to the charged areas and is fused onto the paper with heat — fast for large volumes
3D printerbuilds a solid object layer by layer from a digital model (e.g. melted plastic)
LED and LCD screensLCD: liquid crystals in each pixel are back-lit by LEDs; LED screens use LEDs directly for each pixel
Speakeran electrical signal moves a cone, creating sound waves
3.2.3

Sensors

  • a sensor is an input device that measures a physical property of the environment and sends the reading as data (usually analogue, converted to digital by an ADC)
  • types: acoustic (sound), accelerometer, flow, gas, humidity, infrared, level, light, magnetic field, moisture, pH, pressure, proximity, temperature
  • sensors don’t make decisions — a microprocessor compares the readings with stored values

3.3Hardware

Fast and forgetful, or slow and permanent

Primary storage sits right next to the CPU and is fast; secondary storage keeps your files when the power goes off. When RAM runs out, part of the disk pretends to be RAM.

1

Understand

Four sections and a checklist

3.3.1

Primary storage: RAM and ROM

RAM (random access memory)ROM (read only memory)
Volatile?volatile — contents lost when power is offnon-volatile — contents kept
Can be changed?read and writeread only
Storesdata, programs and parts of the OS currently in usethe bootstrap / start-up instructions (firmware)

Primary storage is directly accessed by the CPU.

3.3.2

Secondary storage

Non-volatile storage for files and programs not currently in use; not directly accessed by the CPU.

TypeHow it worksPros / cons
Magnetic (HDD)spinning platters coated in magnetic material; a read/write head on an actuator arm magnetises tiny areas (sectors on tracks) to store 1s and 0scheap per GB, large capacity · moving parts, slower, can be damaged by knocks
Optical (CD, DVD, Blu-ray)a laser reads pits and lands on the disc surface by the reflection of light; burning creates the patterncheap, portable · small capacity, scratches easily
Solid state (SSD, USB flash, SD)NAND/NOR flash memory: transistors (with control and floating gates) trap electrons to store data — no moving partsfast access, low power, robust, silent · more expensive per GB, limited write cycles
3.3.3

Virtual memory

  • when RAM is full, part of secondary storage is used as if it were RAM — virtual memory
  • data not currently needed is moved (paged) from RAM to the virtual memory, freeing RAM; it is moved back when needed
  • it lets more programs run than RAM alone could hold, but accessing it is much slower
  • if pages are swapped in and out constantly, the computer slows dramatically — disk thrashing
3.3.4

Cloud storage

Data stored on remote servers owned by a provider and accessed over the internet.

AdvantagesDisadvantages
access files from any device, anywhere with internetneeds an internet connection
no need to buy or maintain storage hardware; easy to increase capacityongoing subscription cost
provider backs the data upsecurity and privacy depend on the provider; data could be hacked
easy to share files and collaborateuploading large files can be slow

3.4Hardware

Addresses on the network

Every device that joins a network needs a network interface card with a fixed MAC address, and an IP address so that routers know where to send its data.

1

Understand

Three sections and a checklist

3.4.1

Network interface cards and MAC addresses

  • a network interface card (NIC) lets a device connect to a network (wired or wireless)
  • each NIC has a media access control (MAC) address assigned by the manufacturer — a unique, permanent address
  • a MAC address is 48 bits, written as 6 pairs of hex digits: the first half is the manufacturer ID, the second half the serial number of the device
3.4.2

IP addresses

  • an internet protocol (IP) address identifies a device on a network; it is assigned when the device connects
  • IPv4: 32 bits, written as 4 denary numbers 0–255 separated by dots (e.g. 192.168.0.24)
  • IPv6: 128 bits, written as 8 groups of 4 hex digits separated by colons — created because IPv4 is running out of addresses
  • static IP addresses never change (good for servers); dynamic addresses are allocated each time the device connects and may change
3.4.3

Routers

  • a router connects networks together — for example a home network to the internet
  • it receives data packets, reads the destination IP address and forwards each packet towards its destination
  • it can assign IP addresses to devices on its network (dynamic allocation)
  • a router stores a table of addresses so it knows where to send data
