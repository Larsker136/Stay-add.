10.1Boolean logic

Six gates that make every decision

A logic gate takes one or two binary inputs and produces one binary output by a fixed rule. Combine enough of them and you get adders, memory — a whole CPU.

1

Understand

Two sections and a checklist

10.1.1

What a logic gate is

  • a logic gate is an electronic component that performs a Boolean operation on one or more binary inputs to produce a single binary output
  • 1 means TRUE / on; 0 means FALSE / off
  • a truth table lists every possible combination of inputs and the output for each; n inputs give 2ⁿ rows

10.2Boolean logic

Every input, every output

A truth table for a circuit lists all the input combinations and works out the output for each — gate by gate, column by column.

1

Understand

Two sections and a checklist

10.2.1

Truth tables for circuits

  1. write every input combination in binary order: for 3 inputs, 000 to 111 — 8 rows
  2. add a working column for the output of each gate in the circuit
  3. fill each column from the inputs and the earlier columns, left to right
  4. the last column is the output X
10.2.2

Logic expressions

  • a logic expression writes a circuit in words: X = (A AND B) OR (NOT C)
  • use brackets to show which operation is done first
  • to write an expression from a circuit, start at the output gate and work backwards to the inputs
  • to write one from a truth table, look at each row where X = 1 and join them with OR

10.3Boolean logic

From a problem statement to a circuit

Exam questions describe a situation in words — an alarm, a safety system — and ask for the circuit. Turn each condition into a gate, then wire them together.

1

Understand

Two sections and a checklist

10.3.1

Drawing a circuit from an expression

  1. find the operations inside the innermost brackets — those gates go nearest the inputs
  2. draw each gate with its input wires from A, B or C (an input can branch to more than one gate)
  3. feed the outputs of those gates into the next gate, until one gate gives X

Example: X = (A AND B) OR (NOT C) — an AND gate (A, B) and a NOT gate (C), both feeding an OR gate.

10.3.2

Circuits from problem statements

“The alarm X sounds if the door is open (A = 1) AND the system is armed (B = 1), OR if a window is broken (C = 1).”

  1. give each condition its letter and say what 1 means
  2. translate the words: “and” → AND, “or” → OR, “not” / “is off” → NOT, “either but not both” → XOR
  3. write the expression with brackets: X = (A AND B) OR C
  4. draw the circuit and check it with a truth table
